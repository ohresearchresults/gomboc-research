# Shortest escape deficit
For actual centred physical primal and polar points, let W(i,j) be angular radial escape. Fix intended roots and a positive margin e. Set c(i,j)=max(e-W(i,j),0). Dijkstra on the reverse complete directed graph computes each minimum root-path cost. Edges have nonnegative costs; no hop perturbation is added. Parents always point to an already finalized vertex, so even zero-cost ties give an acyclic forest.

Sum the shortest-path costs over all nonroot starting vertices. This is a finite sum of minima of continuous path-cost functions, hence continuous for a fixed root set and distinct physical points. In a shortest-path forest it equals sum over tree edges of descendant_count times max(e-W(edge),0). The LP retains one hinge per selected tree edge; newly negative edges on that path are not omitted. Root guards are separate. Global-root changes are explicit and no global smoothness claim is made there.

The implementation feeds v_i=weight_i*(W_i-e)+e to the existing hinge corrector with the SAME e. Its deficit is exactly weight_i*max(e-W_i,0), and its selected-forest Jacobian is weight_i times the physical Jacobian. Comparisons use freshly recomputed shortest paths on the candidate body. Uniform volume and the one consistent primal/polar embedding are unchanged. Numerical objective descent is not a polyhedron certificate.

The local route selection is inspired by the supplied full76 source README, whose successful fixed routes used Dijkstra with negative angular escape costs; the descendant-weighted continuous objective and zero-cost handling above are this agent's extension. Source: sources/full76/README.md. Independent SciPy graph distances and a finite-difference scalar physical-merit derivative are recorded in validation.json.
