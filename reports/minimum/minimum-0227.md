## 1. Полученный результат и его границы

Получены три связанных результата.

**Первый — точный критерий первого порядка на полном пространстве настоящих реализаций.** Он учитывает одновременно произвольные смеси VE, EF и VF, действительный объёмный центр масс меняющегося однородного тела и единую взаимно обратную пару M,N. Возможная положительная механическая зависимость выражена через настоящие вторые площадные моменты граней и реакции геометрических инциденций. Она не устраняется подсчётом размерности.

**Второй — критерий разрешения второго порядка для всего конуса положительных зависимостей**, без предположения единственности напряжения. В него входят кривизна настоящих уравнений планарности, вторая производная действительного центра масс и обязательный член 2H² во второй производной обратной метрики. Приведён также достаточный критерий настоящего локального препятствия, но реальный S1U1-кандидат с таким препятствием не построен.

**Третий — новый точный однородный многогранник 10/17/9 с четырьмя смешанными физическими слабыми точками: тремя VE и одной EF.** У него всякая первая проективно-аффинная разрешающая деформация блокируется положительной зависимостью, тогда как полная деформация истинной формы разрешает все четыре точки уже в первом порядке. Метрика остаётся M=N=I, действительный центр масс тождественно равен нулю. Для всей дуги 0<ε≤2⁻²⁰ точно проверено сохранение решётки граней, всех 64 исходных ненулевых рёберных примитивов и всех исходных строгих равновесий. Четыре нуля становятся строго положительными.

Это не только одна дуга: ранг отображения четырёх контактов равен четырём уже на шести истинных деформациях формы с сохранением однородного COM. Поэтому вокруг контроля существует **непустой относительный открытый 12-мерный слой четырёх смешанных контактов** в полном 16-мерном многообразии форма/метрика, каждая точка которого допускает одновременное разрешение. Радиус этого многомерного слоя не вычислялся; 2⁻²⁰ — параметр доказанной одномерной дуги, не радиус шара в пространстве форм.

**Контроль имеет строгие (S,U,H)=(5,4,7), а не S1U1.** Доказанная 12-мерная область также лежит в этом локальном секторе строгих равновесий, а не в множестве кандидатов S1U1. Существование слабого S1U1 в первом слое не установлено. Универсальная плотность proper110, исключение всего E17 и новые канонические количества не получены; внутренний принятый интервал остаётся 34≤C_min≤622. :contentReference[oaicite:0]{index=0}

## 3. Точная локальная постановка: условия выхода, а не список нулей

Пусть Y_i — сырые вершины, g — их действительный объёмный центроид, X_i=Y_i−g, q_f — полюса настоящих максимальных граней относительно g. Для истинного ребра ij с гранями f,h определим четыре примитива

P_ij=X_iᵀM(X_j−X_i), P_ji,
Q_fh=q_fᵀN(q_h−q_f), Q_hf, N=M⁻¹.

Выберем достаточно малую окрестность, где сохраняются решётка граней и знаки **всех исходных ненулевых примитивов**. Для остальных условий построим конечные группы обязательного выхода:

* Для каждой нестрогой вершины, не имеющей положительного исходящего P, группа состоит из её нулевых исходящих P по истинным рёбрам.
* Для каждой нестрогой грани, не имеющей положительного исходящего Q, группа состоит из её нулевых исходящих Q по истинным двойственным рёбрам.
* Для каждого слабого ребра, у которого четыре примитива неположительны и имеется ноль, группа состоит из его нулевых примитивов.

Остальные неравновесные элементы уже имеют положительный примитив, который сохраняется. Исходные строгие S,U,H сохраняются отрицательными примитивами. В каждой из перечисленных групп требуется **хотя бы один положительный примитив**.

Назовём селектором σ выбор одного примитива из каждой группы с последующим удалением повторов. Тогда в указанной окрестности

**то же самое множество помеченных строгих S,U,H и ни одной физической слабой точки ⇔ существует σ, для которого f_σ>0.**

Доказательство прямое. Без положительного выхода прежняя слабая вершина или грань остаётся слабой либо становится новым строгим равновесием. Слабое ребро без положительного выхода остаётся слабым либо становится новым строгим седлом. Обратно, положительные выходы исключают все эти возможности; остальные элементы защищены исходными ненулевыми знаками. В необходимом направлении исходно отрицательные примитивы не могут стать выбранными выходами в достаточно малой окрестности, поэтому достаточно исходных нулей.

Это описание автоматически обрабатывает VF: одна физическая точка может порождать условия на вершине, грани и двух рёбрах одновременно. Выбрать произвольный один нуль «на физическую точку» недостаточно. Нельзя также требовать исчезновения всех алгебраических нулей: нуль на элементе с положительным выходом может быть безвреден. Селекторы не фиксируют заранее какое-либо дерево или дополнительное комплементарное соответствие.

Любая последовательность настоящих разрешений содержит подпоследовательность с одним селектором, поскольку селекторов конечное число. Таким образом последующие критерии исследуют точный локальный геометрический вопрос, а не только произвольно усиленную систему выбранных деревьев.

## 4. Полная производная COM и механическое напряжение

Для записи формул переведём исходное тело аффинным преобразованием в физические координаты g=0,M=N=I. Однородный COM преобразуется аффинно. В дальнейшем M меняется вместе с N=M⁻¹; метрики не выбираются независимо.

Нормируем сырые полюса p_f относительно фиксированного начала координат:

p_f·Y_i=1 для каждой настоящей инциденции i∈f.

Начало остаётся внутри тела при малых движениях, хотя новый сырой COM может отличаться от нуля. Пусть v_i=Y_i′, w_f=p_f′, H=M′. Настоящее касательное пространство задано ровно линейными условиями

p_f·v_i+Y_i·w_f=0, i∈f.                                      (4.1)

Положим

d_f=Area(F_f)/(Vol(P)|p_f|), T_f=E_Ff[xxᵀ].

Это действительные площадные вторые моменты, не суммы свободных масс в вершинах. Нормальная скорость грани равна −w_f·x/|p_f|. Дифференцирование объёмного первого момента по всему движущемуся телу даёт при g=0

**g′=−Σ_f d_f T_f w_f.**                                    (4.2)

Рёбра имеют нулевую площадь и не добавляют отдельного члена. Формула применима и при непростых вершинах: совместимость их движения уже содержится в (4.1).

### Производные двух типов активных примитивов

Для активного P_ij=0 обозначим e=Y_j−Y_i. Тогда

P_ij′=(e−Y_i)·v_i+Y_i·v_j+sym(Y_i eᵀ):H−e·g′.              (4.3)

Для активного Q_fh=0 обозначим b=p_h−p_f. Настоящий центрированный полюс имеет производную q_f′=w_f+p_f(p_f·g′), откуда

Q_fh′=(b−p_f)·w_f+p_f·w_h−sym(p_f bᵀ):H
       +|p_f|² b·g′.                                       (4.4)

Знак метрического члена противоположен (4.3), потому что N′=−H. Последний член — влияние COM **исходного однородного тела**, не центроида отдельно заполненной полярной оболочки.

### Теорема первого порядка

Для фиксированного селектора существует настоящая разрешающая дуга с положительными первыми производными всех выбранных примитивов тогда и только тогда, когда не существует следующего ненулевого положительного механического напряжения.

При коэффициентах λ_a≥0, не всех нулевых, суммируем строки селектора. Для каждой выбранной прямой строки i→j добавим к F_i величину λ(e−Y_i), к F_j величину λY_i. Для каждой выбранной двойственной строки f→h добавим к G_f величину λ(b−p_f), к G_h величину λp_f. Определим

c=Σ_прямые λe−Σ_двойственные λ|p_f|²b,
T=Σ_прямые λsym(Y_i eᵀ)−Σ_двойственные λsym(p_f bᵀ).

Препятствие состоит в существовании вещественных реакций ω_if на настоящих инциденциях, удовлетворяющих

T=0,
F_i=Σ_{f∋i}ω_if p_f,
G_f+d_f T_f c=Σ_{i∈f}ω_ifY_i.                                (4.5)

Это необходимое и достаточное препятствие **первого порядка**, не всех порядков.

**Доказательство.** Подстановка (4.2) в сумму (4.3)–(4.4) даёт

Σ_a λ_a f_a′=Σ_iF_i·v_i+Σ_f(G_f+d_f T_f c)·w_f+T:H.

Она исчезает на всём настоящем касательном пространстве ровно при (4.5): аннулятор ядра полного якобиана инциденций есть его строковое пространство. Метрическое масштабирование можно оставить свободным; при условии trH=0 получился бы T=τI, но каждая активная строка имеет нулевой след T, поэтому τ=0.

Осталось конечномерное выпуклое разделение: набор линейных функционалов имеет общее строго положительное направление ровно тогда, когда их выпуклая оболочка не содержит нуля. Иначе нормированные выпуклые веса дают λ. Полный ранг геометрических уравнений интегрирует найденное касательное направление в настоящую аналитическую дугу той же решётки. SPD и все защищённые строгие знаки открыты; новый COM вычисляется по реальному телу. Это доказывает достижимость, а не только формальное решение линейной системы.

На первом слое минимальное положительное напряжение можно выбрать с поддержкой не более 17 выбранных строк: это следствие выпуклой зависимости в 16-мерном касательном двойственном пространстве. Данный факт только уменьшает поддержку поиска; он не исключает существование такого напряжения.

Уравнение (4.5) показывает дополнительное требование к подлинному препятствию: локальные контактные силы обязаны уравновешиваться **на всех** вершинах и гранях с нагрузкой d_f T_f c, заданной тем же реальным объёмом. Один абстрактный тензор ΣλT=0 этой системы не заменяет.

## 5. Второй порядок: весь конус напряжений и настоящая кривизна

В любой локальной аффинно-нормированной карте используем 23 переменные z и семь геометрических уравнений C(z)=0, rank DC=7. Метрика включена в z. Для выбранного селектора f_i(z₀)=0 положим L=ker DC(z₀).

Выберем v∈L с a_i=df_i(v)≥0 и обозначим I={i:a_i=0}. Найдём любое a₀, удовлетворяющее

DC a₀=−D²C[v,v],

и положим b_i=D²f_i[v,v]+df_i(a₀), i∈I.

**Критерий строгого второго джета.** Дуга, у которой каждый выбранный выход имеет положительный коэффициент в первом или втором порядке и начальная скорость равна v, существует тогда и только тогда, когда

Σ_{i∈I}λ_i b_i>0                                           (5.1)

для каждого ненулевого λ≥0, удовлетворяющего

Σ_{i∈I}λ_i df_i|L=0.

Если таких λ нет, условие пусто. Проверять только одну положительную зависимость нельзя.

Действительно, добавление произвольного w∈L к a₀ меняет вторые коэффициенты на b_i+df_i(w). Строго положительное решение существует ровно при (5.1), по разделению аффинного пространства b+df(L) и открытого положительного ортанта. Тогда

z(ε)=z₀+εv+ε²(a₀+w)/2+O(ε³)

реализуется аналитической дугой C=0: семь поперечных координат исправляют остаток посредством теоремы о неявной функции. Выходы с a_i>0 положительны в первом порядке; остальные — во втором. Далее применяется точная система выхода из раздела3.

Если Σλ_i df_i=Ση_j dC_j, то

Σλ_i b_i=vᵀ[Σλ_i Hess f_i−Ση_j Hess C_j]v.                  (5.2)

Значение не зависит от выбора a₀. Это внутренняя кривизна механического напряжения на настоящем многообразии, а не гессиан свободно движущихся вершин с проигнорированной планарностью.

### Полные моментные и обратнометрические члены

Для настоящей ориентированной триангуляции границы

D=Σ det(Y_a,Y_b,Y_c), J=Σ det(Y_a,Y_b,Y_c)(Y_a+Y_b+Y_c),
g=J/(4D).

При записи производных g₁=g′,g₂=g″ получаем

g₁=(J₁−4g₀D₁)/(4D₀),
g₂=(J₂−4g₀D₂−8D₁g₁)/(4D₀).                               (5.3)

При g₀=0, сыром полюсе p и q=p/(1−p·g), обозначая r₁=p₀·g₁,r₂=p₀·g₂+2p₁·g₁,

q₁=p₁+r₁p₀,
q₂=p₂+2r₁p₁+(r₂+2r₁²)p₀.

Если M=I+εH+ε²K/2+…, то

**N₁=−H, N₂=2H²−K.**                                      (5.4)

В произвольной карте формулы имеют вид N₁=−N₀HN₀ и N₂=2N₀HN₀HN₀−N₀KN₀; (5.4) — физическая нормировка исходной точки, не произвольный сброс транспортированной метрики.

Таким образом общий второй критерий действительно включает смешанные A/B и не переносит формулу чистых A на полярные строки без поправки H².

Можно пользоваться и полиномиально очищенными строками выданного атласа. Там P_ij^clear=4D P_ij, а

Q_fh=(4D)² R_fh/[det(M)H_f²H_h],
H_f=4Dh_f−n_f·J,
R_fh=n_fᵀadj(M)(H_fn_h−H_hn_f).

Множители положительны. На активной строке первая производная просто умножается на этот множитель; при df_i(v)=0 так же преобразуется второй коэффициент вдоль v. Поэтому (4.5), (5.1) и (5.2) не зависят от законного положительного очищения знаменателей.

### Достаточное настоящее локальное препятствие

Пусть некоторый непустой поднабор выбранных выходов имеет λ_i>0, Σλ_i df_i|L=0. Обозначим K₀=∩ker(df_i|L) по его поддержке. Если внутренняя форма (5.2) отрицательно определена на K₀, либо K₀={0}, то в достаточно малой окрестности **нет** строгого разрешения данного селектора.

При наличии последовательности f_i>0 нормированные секущие имеют предельное направление v∈L. Первые производные неотрицательны, а строго положительная зависимость заставляет их все обращаться в нуль: v∈K₀. При K₀={0} это невозможно. Иначе взвешенная сумма f имеет отрицательный ведущий квадратичный член, также противоречие. Если такое препятствие имеется для каждого конечного селектора, оно исключает все локальные разрешения.

Это доказанный достаточный критерий, **не построенное препятствие у S1U1-тела**. Неположительность одной формы, вырожденная квадратичная форма или положительное напряжение первого порядка сами по себе такого вывода не дают. Более высокие порядки и последовательные предварительные деформации могут быть существенны.

## 6. Новый действительный контроль 10/17/9

### Геометрическая конструкция с действительным COM

В плоскости x+y+z=2 возьмём

z₀=(1,1,0), z₁=(0,1,1), z₂=(1,0,1),

### Положительное проективно-аффинное напряжение

В порядке f=(Q12,P05,P18,P23) положим

λ=(0,4/3,16/15,1).

Три прямых контактных тензора удовлетворяют точной положительной зависимости; также Σλe=0 и Σλ|z|²e=0, поскольку все три источника имеют квадрат нормы2. Поэтому λ·f′=0 для **всякой** первой однородно-перезаполненной проективной деформации с последующей аффинной сменой метрики, независимо от действительной ковариации.

Полный 4×9 якобиан по трём проективным параметрам и шести симметричным метрическим параметрам имеет ранг3 и уничтожается этим λ. Один метрический параметр соответствует безвредному общему масштабу. На фиксированном теле зависимость трёх прямых примитивов верна для любого M, поэтому локальное аффинное разрешение при сохранении остальных строгих знаков невозможно.

Это **не** запрет проективно-аффинных движений более высокого порядка или предварительных движений. Утверждается точный барьер первого джета, который следующая истинная деформация преодолевает уже линейно.

## 7. Не один пример: проверенный смешанный контактный слой

Разрешим шесть независимых изменений трёх исходных z_i в плоскости основания:

δz_i=(a_i,b_i,−a_i−b_i), i=0,1,2,

с тем же перерасчётом реального A по (6.1). Это настоящие движения всей конструкции, сохраняющие однородный COM, не движения отдельных интеграционных треугольников.

Для четырёх выходов (Q12,P05,P18,P23) якобиан по (a₀,b₀,a₁,b₁,a₂,b₂) имеет ранг4. Точный минор столбцов(0,1,2,4), с нумерацией от нуля, равен

**−381383555140685/10405493075661013≠0.**

Полный якобиан и все шесть настоящих направлений восстанавливаются приведённым исходником. После перехода в аффинную карту и trace-one метрику ранг сохраняется: соответствующие физические примитивы инвариантны относительно совместного аффинного переноса тела и метрики; положительное масштабирование строк на нулевом уровне ранг не меняет.

Из теоремы о неявной функции и открытости 64 ненулевых знаков следует заявленная область: общий нулевой уровень четырёх контактов — гладкое локальное подмногообразие размерности16−4=12. В достаточно малой окрестности каждой его точки ранг остаётся4, значит можно задать все четыре первые производные положительными и реализовать настоящий выход из слоя. Все четыре физические точки разрешаются одновременно без новых равновесий.

**Это локальная теорема о целом секторе действительных реализаций с четырьмя смешанными контактами.** Она не утверждает ранг4 на всех реализациях данного типа, не идентифицирует его с какой-либо канонической записью и не утверждает наличие S1U1 в этом секторе.

## 9. Что не сработало и что остаётся

Подсчёт11+5 параметров не разрешает контактные неравенства: препятствие первого порядка — не нехватка геометрического ранга, а положительная зависимость ограничений на этом гладком пространстве. Уравнения(4.5) показывают её полный физический состав.

Исчезновение произвольного нулевого примитива не равно исчезновению физической точки; при VF необходимы согласованные условия на всех затронутых элементах. Сохранение двух строгих корней без этих условий не исключает рождения дополнительных строгих равновесий. Фиксированное выбранное дерево тоже может искусственно запретить настоящий выход.

Заморозка центра масс и независимое полярное центрирование неверны. В первом порядке необходимо(4.2), во втором —(5.3) и(5.4). Отдельная положительная зависимость на проективной орбите может исчезнуть при истинном изменении формы, как показано на новых реальных контролях. Напротив, положительная зависимость полного первого джета сама по себе ещё не является препятствием всех порядков.

**Оставшийся конкретный вопрос:** может ли действительный слабый S1U1-кандидат первого слоя с отсутствием строгого седла удовлетворять полным физическим балансам(4.5) для каждого селектора выхода и одновременно избегать всех положительных критических кривизн(5.1)? Ни существование такого кандидата, ни универсальное исключение этих напряжений не установлено. Теперь это вопрос о напряжениях с настоящими поверхностными моментами на настоящем16-мерном многообразии, а не о формальных свободных тензорах или фальшивых геометрических границах атласа.

def face_order(ids,Y,n):
 drop=next(k for k in range(3) if n[k]!=0);keep=[k for k in range(3) if k!=drop]
 seq=sorted(ids,key=lambda i:tuple(Y[i][k] for k in keep))
 def turn(i,j,k):
  a,b,c=[Y[h] for h in (i,j,k)]
  return (b[keep[0]]-a[keep[0]])*(c[keep[1]]-a[keep[1]])-(b[keep[1]]-a[keep[1]])*(c[keep[0]]-a[keep[0]])
 def half(seq):
  out=[]
  for i in seq:
   while len(out)>1 and turn(out[-2],out[-1],i)<=0:out.pop()
   out.append(i)
  return out
 out=half(seq)[:-1]+half(seq[::-1])[:-1]
 if (Y[out[1]]-Y[out[0]]).cross(Y[out[2]]-Y[out[0]]).dot(n)<0:out.reverse()
 return tuple(out)
