### 4.2 An exact joint formula for each actual face lattice

For each physical vertex use a free real vector x_i; for each maximal facet use a free real normalized support q_f. Impose:

```text
q_f dot x_i = 1  for incident pairs;
q_f dot x_i < 1  for every nonincident pair.
```

For every oriented boundary edge (a,b) of a maximal facet and every other vertex c of that facet impose `det(x_a,x_b,x_c)>0`. These constraints make each listed face a strictly convex polygon in its supporting plane. They keep all listed vertices extreme and all facets distinct. They do not forbid nonfacial accidental coplanarities.

There are no omitted facets: every boundary edge of a listed supporting polygon already has its two listed incident facets. The facet adjacency graph of a convex polytope is connected, so an additional facet cannot form a separate component. Thus the listed lattice is the actual lattice. Noncollinear face points and a strictly nonincident vertex give full dimension; all normalized facet supports make zero an interior point.

Fan-triangulate the listed polygons **for integration only**. For every resulting oriented triangle (a,b,c), let `d_abc=det(x_a,x_b,x_c)`. Impose:

```text
D = sum d_abc > 0;
sum d_abc (x_a+x_b+x_c) = (0,0,0).
```

Then `Vol(P)=D/6` and the ordinary first moment is the latter numerator divided by 24. These three quartics impose the body's own filled centroid exactly. They are not equal-vertex-mass equations. Artificial integration diagonals are not mechanical edges.

Define the quadratic polynomials

```text
D_ij = ||x_i||^2 - x_i dot x_j;
B_fg = ||q_f||^2 - q_f dot q_g.
```

A vertex i is strictly unstable iff every D_ij on its actual incident edges is positive. A face f is strictly stable iff B_fg>0 for every other facet g, since its perpendicular foot is `q_f/||q_f||^2`.

For an actual edge ab incident to f,g, a strict saddle is equivalent to **all four**

```text
D_ab > 0, D_ba > 0, B_fg > 0, B_gf > 0.
```

To verify this, put e=x_b-x_a. Its foot parameter is `t=D_ab/||e||^2`, with `1-t=D_ba/||e||^2`. Let `Gamma=||q_f||^2||q_g||^2-(q_f dot q_g)^2>0`. The line foot equals `alpha q_f+beta q_g`, where **alpha=B_gf/Gamma and beta=B_fg/Gamma**. This proves both segment-interiority and normal-cone tests without a simple-vertex assumption.

The generator takes an OR over **every** unstable root and every stable root, excludes other roots, and excludes a saddle on every true edge. No root symmetry or metric restriction drops a case. All coordinates and normals are arbitrary reals; there is no bounded search box, rationality assumption, shape-thickness bound, or fixed-normal restriction.

Two complete variants are emitted:

- `strict_only`: each nonroot/no-saddle disjunction requires at least one primitive <=0. This means exactly the requested strict counts, allowing possible additional boundary/weak features.
- `weak000`: each such disjunction requires a primitive <0. This excludes additional weak equilibria as well and matches the construction acceptance regime.

Accordingly, either convention can be audited without silently strengthening the hypothesis. Coplanar maximal polygonal faces and nonsimple contacts remain exact parts of the incidence equations, not perturbation limits.

# Python 3.13.5; standard library only; generates formulas, NOT exclusions.
from itertools import combinations, permutations, product
from collections import Counter, defaultdict
from hashlib import sha256
from pathlib import Path
import json, sys

def need(ok, why):
    if not ok: raise ValueError(why)

def rot(c):
    c=tuple(c); k=c.index(min(c)); return c[k:]+c[:k]

def normfaces(fs):
    a=tuple(sorted(rot(c) for c in fs))
    b=tuple(sorted(rot(tuple(reversed(c))) for c in fs))
    return min(a,b)

def edges(fs):
    return {tuple(sorted((c[i-1],c[i]))) for c in fs for i in range(len(c))}

def canonical(n, fs):
    es=edges(fs); deg=[sum(i in e for e in es) for i in range(n)]
    blocks=[[i for i in range(n) if deg[i]==d] for d in sorted(set(deg))]
    best=None; bf=None
    for bs in product(*(permutations(b) for b in blocks)):
        order=sum((tuple(b) for b in bs),()); p={v:i for i,v in enumerate(order)}
        # Degree ordering is part of this canonical-code convention.
        key=tuple(sorted(tuple(sorted((p[a],p[b]))) for a,b in es))
        if best is None or key<best:
            best=key; bf=normfaces(tuple(tuple(p[v] for v in c) for c in fs))
        elif key==best:
            bf=min(bf,normfaces(tuple(tuple(p[v] for v in c) for c in fs)))
    return best,bf

def three_connected(n, es):
    adj=[set() for _ in range(n)]
    for a,b in es: adj[a].add(b); adj[b].add(a)
    if min(map(len,adj))<3: return False
    for k in (0,1,2):
        for dead in combinations(range(n),k):
            live=set(range(n))-set(dead); seen={min(live)}; todo=list(seen)
            while todo:
                for w in adj[todo.pop()] & (live-seen): seen.add(w); todo.append(w)
            if seen!=live: return False
    return True

def facecheck(n,fs):
    es=edges(fs); darts=Counter((c[i-1],c[i]) for c in fs for i in range(len(c)))
    need(all(len(c)>=3 and len(set(c))==len(c) for c in fs),'bad face')
    need(set(v for c in fs for v in c)==set(range(n)),'unused vertex')
    need(n-len(es)+len(fs)==2,'Euler')
    need(all(darts[a,b]==darts[b,a]==1 for a,b in es),'orientation')
    need(three_connected(n,es),'not 3-connected')
    return es

def merge_faces(fs, edge):
    a,b=edge
    hits=[c for c in fs if any({c[i-1],c[i]}=={a,b} for i in range(len(c)))]
    need(len(hits)==2,'edge incidence')
    darts=[(c[i-1],c[i]) for c in hits for i in range(len(c))
           if {c[i-1],c[i]}!={a,b}]
