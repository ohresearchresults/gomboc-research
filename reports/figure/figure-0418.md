## Новая вычислительная постановка, пригодная для продолжения

Для тела с новыми плоскостями `n_i·x≤1` обозначим его действительные объём, первый момент и центр через `V`, `M`, `c=M/V`. На новой активной грани `F_i` положим

`H_i = ∫_{F_i} xxᵀ / |n_i| dA`,

`J_i = ∫_{F_i} x / |n_i| dA = H_i n_i`.

Внутри области неизменной активной структуры производные по нормали новой плоскости равны

`dV = −J_iᵀ dn_i`,

`dM = −H_i dn_i`,

`D_{n_i}c = (−H_i + c J_iᵀ)/V`.

Поэтому масштабно-инвариантная массовая цель

`L = |c|² / V^(2/3)`

имеет градиент

`∇_{n_i}L = [−2H_i c + (8/3)|c|²J_i] / V^(5/3)`.

Эта постановка позволяет сначала искать действительное массовое замыкание внутри достаточной области механических ограничений, а затем использовать общий сдвиг нормалей как точный трёхпараметрический контроллер. Она не ограничивает всю работу единственной траекторией общего сдвига.

Достаточное условие единственного устойчивого положения при центре0 задаётся положительными полярными стрелками

`n_i·(n_j−n_i) > ε |n_i|²`.

Если каждый полярный вход, кроме одного корня, имеет такую стрелку и все пути достигают корня, остальные входы не могут быть неустойчивыми полярными вершинами. Строго положительные стрелки увеличивают радиус, поэтому циклы невозможны. После **доказанного** действительного массового замыкания это даёт моностабильность физического тела. До массового замыкания это только утверждение относительно проверочного центра0.

Такой положительный граф — достаточный сертификат исключения лишних экстремумов, а не количественная замена истинного рёберного бассейна. Полная механическая проверка всё равно должна учитывать все актуальные вершины, максимальные грани, настоящие рёбра и дополнительные слабые положения.

## Разделение трёх типов новых объектов

Подготовленная точная цепочка намеренно различает следующие объекты.

**Рационально закреплённые срезы.** Все компоненты новых нормалей округляются на объявленную рациональную сетку. Из буквальных плоскостей заново строится тело. Его собственный центр вычисляется точно; маленький ненулевой центр не называется нулём.

**Алгебраический общий массовый корень.** Для закреплённых нормалей рассматривается семейство

`G6 ∩ ⋂_i {(n_i+δ)·x≤1}`.

При фиксированной актуальной структуре координата каждой вершины является отношением аффинного числителя к аффинному знаменателю по `δ`: изменение матрицы трёх опорных нормалей имеет ранг один. Подготовленный проверяющий код проверяет тождества активных инцидентностей, строгие неинцидентные зазоры, положительные тетраэдры, интервальное сжатие массового отображения и каждый примитивный механический знак на одном замкнутом изолирующем боксе. Рациональная середина бокса не отождествляется с алгебраическим корнем.

**Рациональные арифметические спутники.** После округления физических координат заново строится полная оболочка и вычисляется её собственный равномерный центр. Только затем центр вычитается и применяется объявленное рациональное масштабирование. При точном подтверждении строгого включения в G6 такое тело снова является элементом семейства дополнительных полупространств G6, хотя число новых граней может превосходить21. Для него требуется фактическое `E<311`, а не применение достаточного условия `m≤21` вне его области.

Подготовленная независимая массовая проверка использует двумерные проекционные формулы площади и первого момента каждого максимального многоугольника. Она не считает интеграционные диагонали рёбрами многогранника.

## Что нельзя выводить из этого поиска

Нулевое значение цели, в которой малые положительные радиальные полосы отбрасываются численным порогом, не доказывает исчезновение соответствующих строгих пар. Именно поэтому была добавлена отдельная процедура положительных физических запасов вне оставленных макроскопических корней и положительных полярных запасов вне единственного полярного корня.

Уменьшение нормированной высоты радиального бассейна также необходимо сопоставлять с `V/R³` и отношением вписанного радиуса к описанному. Уход к тонкому телу может уменьшать используемую энергию, не осуществляя требуемого конечного слияния. Подготовленные точные диагностические процедуры вычисляют эти величины вместе, а не объявляют уменьшение одного скаляра механическим успехом.

Ни остановка SQP, ни отрицательный запас в последней итерации, ни изменение числа вершин, ни неудача отдельной полярной цепи не являются исключением всего многосрезового семейства.
