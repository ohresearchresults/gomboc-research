## A finite new-root construction

Let g be the **actual integrated centroid of the original R82 body** K, and write its centred polar vertices as

`q_i = Y_i/(1−Y_i·g)`, where `Y_i=n_i/1000000`.

Let `u=q_7`, `v=q_18`, `a=u·u`, `b=v·v`, `c=u·v`, and `D=ab−c²`. For a chosen positive rational ε, define

`α=(1+ε)b(a−c)/D`,

`β=(1+ε)a(b−c)/D`,

`w=αu+βv`.

The literal R82 directions are linearly independent, so D>0; the source checks it exactly. The construction gives

`u·(w−u)=εa>0`,

`v·(w−v)=εb>0`.

Thus both old stable roots receive strictly positive outgoing polar chords to the **new** point w. The other old polar vertices retain their old positive outgoing witnesses. Old18 is a largest-radius old polar vertex; the second displayed inequality implies `|w|>|v|`. The code checks the stronger literal statement `|w|²>max_i|q_i|²`, so w strictly supports the entire new polar hull in its own radial direction.

Consequently `conv({q_i}∪{w})` has exactly one strict unstable vertex and no weak unstable vertex. Equivalently,

`K₁ = K ∩ {x : w·x ≤ 1+w·g}`

has exactly one strict stable facet and no weak stable facet **at reference centre g**. That facet is the new cutting plane. This conclusion permits old facets to disappear. It does not require old polar points to remain extreme: their positive chords to retained points still exclude a supporting radial hyperplane.

This avoids the old-root target prohibited by the few-cut gate. It does not evade the associated mass burden by assertion: the finite cut changes the uniform centroid, and the homogeneous class is still unknown until the actual filled K₁ is integrated.

### Two additional cuts without creating a reference stable root

`d = |w|² e / [2(|w|²+|e|²)]`,

`z₊=w/2+d`, `z₋=w/2−d`.

Then

`|d|² ≤ |w|²/16`,

`z₊·(w−z₊) = z₋·(w−z₋) ≥ 3|w|²/16 > 0`.

def dot(a,b):
    return sum(x*y for x,y in zip(a,b))

def add(a,b):
    return tuple(x+y for x,y in zip(a,b))

def sub(a,b):
    return tuple(x-y for x,y in zip(a,b))

def scale(a,t):
    return tuple(x*t for x in a)

def cross(a,b):
    return (a[1]*b[2]-a[2]*b[1],
            a[2]*b[0]-a[0]*b[2],
            a[0]*b[1]-a[1]*b[0])

def matvec(A,x):
    return tuple(dot(row,x) for row in A)

def inverse(A):
    determinant=dot(A[0],cross(A[1],A[2]))
    assert determinant>0
    columns=[scale(cross(A[1],A[2]),1/determinant),
             scale(cross(A[2],A[0]),1/determinant),
             scale(cross(A[0],A[1]),1/determinant)]
    return tuple(tuple(columns[j][i] for j in range(3))
                 for i in range(3))

def row_times_matrix(n,A):
    return tuple(sum(n[k]*A[k][j] for k in range(3))
                 for j in range(3))

def identity(path):
    b=Path(path).read_bytes()
    return {'bytes':len(b),'sha256':hashlib.sha256(b).hexdigest()}

def write_json(path,obj):
    raw=(json.dumps(obj,sort_keys=True,separators=(',',':'))+'\n').encode()

def qstrings(x):

def integer_halfspace(n,h):
    assert h>0
    row=list(n)+[h]
    den=lcm(*(x.denominator for x in row))
    out=[int(x*den) for x in row]
    common=0
    for x in out:
        common=gcd(common,abs(x))
    assert common>0
    out=[x//common for x in out]
    assert out[3]>0
    return out

    ww=dot(w,w)
