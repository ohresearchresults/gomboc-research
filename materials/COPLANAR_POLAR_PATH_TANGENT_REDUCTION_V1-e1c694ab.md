# COPLANAR_POLAR_PATH_TANGENT_REDUCTION_V1

Coordinator-authored analytic result and open application. This is a self-contained proof, not a computed polyhedron, a canonical exclusion, or a claim of a new literature theorem. No numerical computation produced it. Global research bounds remain 34 <= Cmin <= 622. The new application problem is whether the criterion yields an obstruction beyond all consecutive four-pole gates for a convex pentagonal polar face.

## Scope and connection to the actual geometry

Let q_i be actual polar poles in an affine plane Pi in R^3 not through the origin. For a physical inverse metric N positive definite, an arrow i -> j means D_ij = q_i^T N(q_j-q_i) >= 0. For poles incident to one true primal vertex v, v.q_i=1 gives just such a plane. Only arrows whose segments are true polar edges may be counted as equilibrium edges; linear algebra may of course use other differences without counting them.

Select m directed arrows, not necessarily the whole boundary. Write q_i = A p_i + b, where A is a rank-two 3 by 2 matrix, p_i in R^2, and b is not in span(A). Let e_l = p_j-p_i for selected arrow l=(i,j). Define E as the m by 2 matrix with row e_l^T, and sym(B)=(B+B^T)/2. All claims are invariant under changing these affine coordinates.

For a convex polygonal polar face, every four consecutive distinct poles form a convex quadrilateral. The sharp cyclic-quad theorem of the fully read immutable parent minimum-0192, SHA256 662e3cea120774e0849ae53566fe634335f4a2c4a7560d82ba5bfa79f47aba15, uses only the three consecutive arrows. Its fourth, closing segment need not be an equilibrium edge. Thus that theorem applies unchanged at true primal vertices of degree greater than four. This extension does not turn a polar diagonal into a true edge.

## Theorem 1: remove the normal quadratic coefficient

There exists N positive definite realizing all selected weak arrows if and only if there exist H positive definite in Sym_2 and k in R^2 such that

    e_l.k + p_i^T H e_l >= 0  for every selected l=(i,j).              (1)

The equivalence also holds with all inequalities strict.

Proof. L=[A b] is an invertible 3 by 3 matrix. Write

    L^T N L = [[H,k],[k^T,c]].

Then q_i corresponds to (p_i,1), while q_j-q_i corresponds to (e_l,0). Consequently D_ij=p_i^T H e_l+k^T e_l, independently of c. Positive definiteness of this block matrix implies H positive definite. Conversely, for any H positive definite and any k, choose c>k^T H^{-1} k. The block matrix is positive definite by its Schur complement, hence defines a genuine N=L^{-T}[[H,k],[k^T,c]]L^{-1}. This proves both versions. In particular, k is truly free here; no independently chosen primal metric has been introduced.

## Theorem 2: exact finite elimination of k

Define the nonnegative zero-displacement cone

    K = {lambda in R^m: lambda >= 0 and E^T lambda = 0}.

Choose one nonzero vector lambda^(r) on each extreme ray of K. If K={0}, the ray list is empty. Define

    S_r = sum_l lambda_l^(r) sym(p_i e_l^T),  l=(i,j).               (2)

Then all selected weak arrows admit N positive definite if and only if there exists H positive definite satisfying

    tr(H S_r) >= 0  for every extreme ray r.                        (3)

All selected arrows admit a strict realization if and only if there exists H positive definite satisfying tr(H S_r)>0 for every ray. An empty ray list imposes no restriction, and both weak and strict realizations exist.

Proof for weak arrows. Fix H and put a_l=p_i^T H e_l. The finite-dimensional linear inequality alternative for E k >= -a says exactly that this system is feasible if and only if lambda.a>=0 for every lambda>=0 with E^T lambda=0. The latter scalar is tr(H S(lambda)). K is a pointed polyhedral cone, hence is generated by its finitely many extreme rays. It is therefore sufficient and necessary to check (3). Theorem 1 recovers N.

For strict arrows, necessity follows because each nonzero nonnegative lambda has at least one positive entry. Conversely, if every extreme-ray scalar is positive, choose epsilon>0 smaller than every ratio tr(H S_r)/(sum_l lambda_l^(r)). The ratio list is finite and positive. Applying the weak alternative to E k >= -a+epsilon*1 gives a k with every arrow at least epsilon. If K={0}, the same weak alternative applies for any chosen positive epsilon. This proves the strict assertion.

Each extreme ray is a minimal positive dependence of the selected planar edge vectors. It has support of size at most three. Indeed, if a ray had more than three positive coordinates, the nullspace of the two-dimensional edge matrix restricted to that support would have dimension at least two, giving a linearly independent perturbation preserving nonnegativity for sufficiently small positive and negative perturbations. The ray would not be extreme. Two-element supports occur for oppositely directed parallel edge vectors. One-element supports would require a zero edge, which does not occur for distinct true vertices.

## Theorem 3: exact matrix-cone obstruction, including the weak boundary

Let C=cone{S_r} in Sym_2. All weak arrows admit N positive definite if and only if C contains NO nonzero negative-semidefinite matrix. A zero matrix in C is not by itself a weak obstruction.

Proof. If X in C is nonzero negative semidefinite, then tr(H X)<0 for every H positive definite, contradicting (3). Conversely suppose there is no feasible H. Then the open convex cone of positive-definite matrices is disjoint from the closed polyhedral cone C^*={H:tr(H X)>=0 for X in C}. Separating these cones gives a nonzero Y with tr(Y H)>=0 for every H positive definite and tr(Y Z)<=0 for every Z in C^*. The first property gives Y positive semidefinite; the second gives -Y in (C^*)^*=C because C is closed. Thus -Y is a nonzero negative-semidefinite matrix in C, a contradiction. No semidefinite-programming attainment assumption is being used: the only closed cone required here is the finite generated cone C.

For strict arrows, the corresponding obstruction is sharper: the convex hull of the finitely many S_r must contain no negative-semidefinite matrix, INCLUDING the zero matrix. This condition is equivalent to strict feasibility when the ray list is nonempty. Necessity is immediate. For sufficiency, the compact convex hull and the closed negative-semidefinite cone are disjoint, so strict separation provides a positive-semidefinite H for which all tr(H S_r)>0. Perturb H by a sufficiently small positive multiple of I to obtain H positive definite while retaining these finitely many strict inequalities. An empty ray list was already handled in Theorem 2. Consequently weak feasibility and strict feasibility must not be silently identified in the general theorem.

The obstruction in Theorem 3 can be read as an explicit arrow certificate. Choose nonnegative ray coefficients t_r and put lambda=sum_r t_r lambda^(r). Then E^T lambda=0 and

    sum_l lambda_l D_l = tr(H S(lambda)).

When S(lambda) is nonzero negative semidefinite, the right side is strictly negative for every physical N positive definite; the assumed weak arrows make the left side nonnegative. This is the promised local contradiction.

## Corollary 4: a pentagonal four-arrow path is a one-parameter 2 by 2 test

For four selected arrows whose e_l span R^2, the nullspace of E^T has dimension two. Hence K, a pointed cone in that two-dimensional space, has at most two extreme rays. In particular, this applies to the four consecutive boundary arrows of a strictly convex pentagon.

With no extreme rays, the path is strictly feasible. With one ray, weak feasibility fails exactly when its S_1 is nonzero negative semidefinite. With two rays, define

    S(t)=(1-t) S_1+t S_2,  0<=t<=1.

Weak feasibility fails exactly when some t satisfies

    tr(S(t)) < 0  and  det(S(t)) >= 0.                              (4)

This is precisely the condition that a symmetric 2 by 2 matrix be nonzero negative semidefinite. Every nonzero nonnegative combination of S_1,S_2 is a positive multiple of such an S(t); conversely every S(t) belongs to C. Cases where the combination is zero are intentionally not excluded by (4).

The trace in (4) is linear and the determinant quadratic in t. Thus for rational pole coordinates and rational extreme-ray representatives, this is an exact finite univariate decision problem: intersect [0,1] with the trace-negative half interval and the determinant-nonnegative intervals, treating roots and endpoints exactly. There is no numerical SPD search left in this local four-arrow problem.

Strict feasibility for two rays instead fails exactly when some S(t) is negative semidefinite, including zero. It can be tested by tr(S(t))<=0 and det(S(t))>=0. For a symmetric 2 by 2 matrix, trace zero and nonnegative determinant force both eigenvalues zero, so this correctly retains the zero case. For one ray the same inclusive test applies to S_1.

## What is not proved, and the next scientific question

No explicit convex pentagon has yet been constructed whose two consecutive four-pole windows both pass the parent's chi>3/4 gate while the complete four-arrow path fails the new pencil test. It remains open here whether such genuinely additional pentagonal obstructions exist, or whether the two quad gates already suffice for every convex pentagonal boundary path. This can now be studied exactly rather than by optimizing full 3 by 3 metrics.

For longer coplanar paths, the same reduction works, but the positive edge-dependence cone can have more rays. Every elementary edge circuit has support at most three. A common-metric obstruction may combine several circuits; independent feasibility of each circuit is not a proof of joint feasibility. Standard conic dimension bounds in Sym_2 give a representation of any resulting certificate matrix using at most three of the S_r, but no further minimal-support theorem is asserted here.

All this is a local pole-geometry theorem. It neither verifies that an arbitrary polygon is the polar face of a uniformly filled E17 polyhedron at its own centroid, nor covers the remaining canonical E17 incidences, nor supplies an attaining110 body. To use it globally one must substitute the actual q_i=n_i/(b_i-n_i.g) from the same actual volume centroid g and retain the required true arrows. The existing sharp-quad halfspaces are actual geometric special cases, not replacements for those centroid dependencies.
