## 3. Why all rooted trees are the correct physical alternatives

Write Xi=Yi-g in the parallel family and define

 Sij=sym[Xi (Yj-Yi)^T], Dij(M)=tr(M Sij).

For SPD M, a strict unstable vertex is characterized by Dij<0 for every true adjacent j. A vertex that is not strict unstable has at least one true adjacent weak exit Dij>=0. Every such exit strictly increases the quadratic radial value, because

 Xj^T M Xj-Xi^T M Xi = 2Dij+(Yj-Yi)^T M(Yj-Yi)>0.

Thus any selection of one weak exit at each nonroot vertex is acyclic. If the body had exactly one strict unstable vertex, all selected paths would end at it and the selected arrows would form one of the labelled rooted spanning trees of the true graph. The exhaustive compiler enumerates every (n-1)-edge subset, rejects cycles by union-find, and orients each resulting spanning tree toward each possible root. It obtains 4879 unrooted trees, hence 48790 primal rooted alternatives. A farthest vertex in an SPD norm is strict unstable, so excluding exactly one implies U>=2 rather than only U!=1. Weak contacts are not discarded anywhere in this reduction.

then no nonzero PSD M can make all its weak Dij nonnegative: tr(M A_I)>0 contradicts tr(M A_I)=-sum wi Dij<=0. This is the entire one-sided exclusion mechanism. It is not an inference from sampled metrics or a separately centred polar.
