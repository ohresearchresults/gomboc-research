## 1. General positive-projective face blowup

Let P be any fixed bounded full-dimensional convex three-polytope. Let h(x)=1-n.x be nonnegative on P, with zero set equal to one proper nonempty face F. Assume h is strictly positive at every vertex outside F. For epsilon>0 put

```
Q_epsilon={x/(h(x)+epsilon): x in P}.
```

The positive denominator makes this a genuine projective image of P. Let k=dim F in{0,1,2}. Choose z in F, put K=span(F-F), and choose a linear complement Q of K in ker n. Then

```
R3 = W direct-sum Q,
W=span(F)=span(z) direct-sum K,
dim W=k+1, dim Q=2-k.
```

This is valid because n.z=1, so z is independent of ker n. Write x=x_W+pi(x), with pi(x) in Q. Define the invertible linear map

```
A_epsilon(x_W+q)=epsilon x_W+q.
```

For each labelled original vertex v, the normalized projective image tends to

```
v,                     when v is in F;
pi(v)/h(v),            when v is outside F.
```

Indeed, the first denominator is epsilon and v belongs to W; for the second, its W coordinate is epsilon v_W/(h(v)+epsilon) and its Q coordinate is pi(v)/(h(v)+epsilon). There are finitely many vertices, so all normalized labels converge and their convex hulls converge. The limiting hull is

```
J=conv(F union B),
B=conv{pi(v)/h(v): v a vertex of P outside F}, B subset Q.
```

No transformed mass assignment is used. A_epsilon is applied to the actual uniformly refilled Q_epsilon, so the resulting body remains uniform and its actual volume centroid is affinely transported.

### Full dimension

B has affine dimension 2-k. To see this, an affine linear relation on B would have the form ell(pi(v))/h(v)=c. Thus ell(pi(v))+c n.v=c for every off-F vertex; it holds on F too because pi(F)=0 and n.F=1. A nontrivial affine relation of this kind would put all of P in a hyperplane, contrary to full dimension. Therefore B has the claimed dimension. Since F lies in n.x=1, B lies in n.x=0 and their direction spaces are complementary, J has affine dimension k+(2-k)+1=3. It has positive actual volume.

### Vertex counts

If k=2, Q={0}, so J is the pyramid conv(F,0), with f_0(F)+1 true vertices.

If k=1, F is an edge and B is a nondegenerate interval. The affine spans are skew, so J is a tetrahedron, with exactly four vertices.

If k=0, F={z}, K={0} and pi(v)=v-(n.v)z. Hence

```
pi(v)/h(v)=z+(v-z)/h(v).
```

These are the central projections from z onto n.x=0. The tangent cone of P at z is generated by its true incident edge rays. All off-F directions have h(v)>0, so normalizing such a conical combination produces a convex combination of the projected adjacent vertices. Conversely each true incident edge ray is extreme and yields a distinct corner of this section. Thus B is exactly a projective vertex figure with deg_P(z) true corners. J is a pyramid over that polygon and has deg_P(z)+1 true vertices.

This proves a fully explicit arbitrary-face projective blowup for fixed P and h. It includes coincident and nonextreme images of off-F labels; they remain contained in J and do not need to be discarded before a weak-tree limit argument.
