About this map

Each card is a saved research branch. Every curve is an explicit parent link from the public catalog. All branches are shown by default. The dropdown can focus on one root. Separate trees have no recorded parent link between them.

Open and closed describe saved checkpoints, not current activity or whether a mathematical claim was proved. Titles preserve the public English branch labels; report titles preserve the indexed wording and may be in another language.

Linked reports are historical AI scientific reports, including incomplete and superseded claims. The preserved C622 endpoint has supplied exact checks. C < 500 remains open; Minimum’s proposed C ≥ 34 bound still needs a consolidated proof. The checks are not external peer review.

A branch with no linked report has no report link in this index; this does not establish an absence of evidence. Material links are outside this map’s catalog schema.
