# Release coverage

This release contains 158,763 selected scientific file paths (2.81 GB before compression), 898 saved AI scientific reports, 1,101 selected source/proof materials and 174 recorded research branches. Identical files are retained at multiple paths where historical dependencies require that layout. Download sizes and file hashes describe the actual exported bytes.

The private archive contains 930 saved AI outputs, including unrelated research and operational records. It also contains raw chats, human messages, private correspondence, account state, application source and manuscript work. Those are outside this release. No paper, preprint, manuscript PDF, LaTeX source or paper-page image is included.

The current accepted construction in the retained record is C622. The target C<500 remains open. Minimum’s C≥34 bound is a working claim that still needs a consolidated publication proof. A name such as `own110` in an exploratory file is not a certificate.

Known collection gaps remain: seven submitted turns had no collected outcome; the J143 translation-mass-closure note lacks confirmed companion files `input143.py`, `exact_translation143.py`, `quartic_census143.py` and `TRANSLATION143_EXACT_RECIPE.json`; the full KL13C 100-file capsule has not been confirmed. Some further encoded blocks are omitted from the public text pending content review. These limitations affect those records, not the standalone C622 input/check closure.

Public derivatives remove private identifiers and document encoded-block omissions. A small group of original NumPy object caches is converted to non-object arrays where validated; conversion metadata explains the representation. A symbolic pickle cache and unreviewed binary payloads are not released. Imported originals remain unchanged in the private archive.

The release was screened with three independent GPT-6.1 Sol advisers, partitioned GPT-6 Luna Max reviews, whole-file pattern/credential scans, static array/capsule inspection and exact file hashes. These were content and reproducibility checks; they do not constitute external scientific peer review or a guarantee that every historical claim is correct. The large text reviews were risk based, not a claim that every line received independent human scrutiny.

For later historical experiments, use the source’s stated dependencies and a separate working copy. Many original scripts write their outputs beside inputs. The [C622 quickstart](../C622/README.md) is the freshly exercised standard-library reproduction path.
