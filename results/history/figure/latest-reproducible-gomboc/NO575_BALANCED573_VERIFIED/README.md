## Воспроизведение
`python REPLAY.py` восстанавливает каждую координату без оптимизатора/исходной гладкой поверхности, запускает два независимых полных точных проверяющих скрипта, граф и отрицательные тесты. Для второго скрипта требуется NumPy, но все решающие знаки вычисляются целыми числами произвольной точности.
Первый скрипт отдельно работает только со стандартной библиотекой:
`python -S verify_rational.py . --allpairs`.
Не используйте `python -O`: проверки содержат assert.

OBJ и ASCII STL содержат точные конечные десятичные **исходные** координаты I_i/D, не округлённую центрированную таблицу. Их центр масс — B0/Q; центрированный список есть в vertices.csv.gz. В STL единичные нормали округлены только для отображения: геометрия определяется точными вершинами и ориентацией треугольников. Считывание всех координат обратно как рациональных чисел выполнено. Конкретный визуализатор/принтер может округлять; устойчивость к такому округлению не утверждается.

Проверка независима на уровне двух программ внутри исследования, но это не внешняя независимая экспертиза или формализация в proof assistant. Короткие графовые расстояния относятся только к данному точному центру данного тела, не являются оценкой для других деформаций.
